プライバシーポリシー

制定日：2026年10月20日

「ジャンプスケア予報」（以下、本サイト）は、映画の急に驚かされる場面の時刻を、ネタバレなしで共有するためのサイトです。本サイトで取り扱う情報について、以下のとおり定めます。

1. 取得する情報

  • Googleアカウントでログインした際に Google から提供される、メールアドレス、表示名、プロフィール画像のURL、アカウントを識別するID
  • ログインせずに投稿した場合に発行される、ゲスト用の識別ID（この端末のブラウザに保存されます）
  • 投稿した方が投稿・登録した内容（作品名、時刻、強さ、種類、直前の目印など）
  • 通報や「この人を非表示」の操作の記録

ログインせずに閲覧するだけの場合、本サイトが個人を特定できる情報を取得することはありません。

2. 利用目的

  • 投稿者を識別し、本人による投稿の削除などを可能にするため
  • ネタバレや迷惑行為への対応（非表示、利用停止）のため
  • 連続投稿の制限など、サイトを安全に運営するため

メールアドレスや表示名が、ほかの利用者に公開されることはありません。投稿には、個人を特定できない識別子のみが紐づきます。

3. 第三者への提供

法令にもとづく場合を除き、取得した情報を第三者に提供することはありません。広告目的での利用もしません。

4. 外部サービスの利用

本サイトは、データの保存とログインに Supabase、ログイン手段に Google、サイトの配信に GitHub Pages を利用しています。各サービスでの情報の取り扱いは、それぞれのプライバシーポリシーに従います。

5. 情報の削除

ご自身の投稿は、サイト上の「削除」からいつでも消せます。アカウント情報の削除をご希望の場合は、下記の窓口からご連絡ください。

6. お問い合わせ

GitHub の Issues からご連絡ください。

7. 改定

本ポリシーは、必要に応じて改定することがあります。改定後の内容は、このページに掲載した時点から有効になります。
