# ジャンプスケア予報

https://shikapenne.github.io/

映画の「急に驚かされる場面」がいつ来るかを、ネタバレなしで共有するサイトです。

- フロント: `index.html`（GitHub Pages で配信）
- データ・ログイン: Supabase（プロジェクト `jumpscare-yoho`、東京リージョン）
  - 作品、投稿、通報、BAN、個人の非表示設定、作品追加リクエストを保存
  - アクセスルール（RLS）で、他人の投稿の書き換え禁止・BAN・通報3件で自動非表示・連投制限を管理

ページ内の Supabase キーは公開用（publishable）キーで、ブラウザに置いて問題ないものです。権限はすべてサーバー側のルールで制御しています。
